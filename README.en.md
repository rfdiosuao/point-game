# Pointless? — Constellation Run

A browser mini-game built around points and real constellation patterns. Guide the white point through numbered stars in order while avoiding hazardous red points and tracking enemies.

## Play Online

<https://rfdiosuao.github.io/point-game/>

## Run Locally

Open [`index.html`](index.html) directly in a modern browser. No build step or package installation is required.

## Controls and Goal

- Move the white point through the play field.
- Connect the numbered constellation points in sequence.
- Avoid red hazards and enemies that follow the player.
- Complete the constellation to finish the level.

## Technology

The game is implemented as a self-contained HTML browser experience.
